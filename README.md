### Hi, I'm Ahmed Aziz 👋

**AI Engineer: LLM agents · agentic RAG · production backends**

I build LLM agents and RAG systems, along with the backends and infrastructure that run them in production. Most of my work sits where AI meets software engineering: multi-agent workflows in LangGraph, retrieval pipelines on PostgreSQL/pgvector, FastAPI services, and containerized deployments on Kubernetes.

Software engineering graduate from **ENISo** (Diplôme National d'Ingénieur, EUR-ACE, 2026). I've built AI systems during internships at **EY** and **Talan**. Based in Tunisia and **open to AI engineer roles**.
